# agent/ — 에이전트용 네임스페이스

이 디렉터리는 사람이 아니라 **AI 에이전트·자동화 도구가 읽기 위한 산출물**만 둔다.
사람용 화면(HTML)은 레포의 다른 경로에 있고, 같은 원본 데이터에서 함께 빌드된다.

## 규칙

- 형식은 JavaScript 없이 읽을 수 있는 **JSON(원본) + Markdown(요약)** 만 사용한다.
- 각 산출물은 대응하는 인간용 경로를 미러링한다. (`/kanban/` ↔ `/agent/kanban/`)
- 이 디렉터리 파일은 빌드 산출물이다. 직접 수정하지 말고 원본 데이터를 고쳐 다시 빌드한다.
- 공개 레포이므로 담당자 ID 등 개인 식별 정보는 마스킹된 상태로만 게시한다.
- JSON은 `schemaVersion` 필드를 가진다. 필드 의미가 바뀌면 버전을 올린다.
